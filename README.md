# YES EDU — Institutional Management Platform (ERP)
### Modern 3D Animated Landing Page

A premier, high-converting 3D animated landing page for **YES EDU**, Bangladesh's all-in-one educational ERP system tailored for **Schools, Colleges, and Madrasas**.

---

## 🌟 Key Features

1. **Interactive 3D WebGL Campus (Three.js)**:
   - Dynamic 3D isometric educational campus building with glowing holographic rings, laser biometric scan sweeps, and floating data particles.
   - Interactive mouse tilt and mobile touch responsiveness.
   - 4 floating holographic status badges (*Biometric Gate Sync*, *Automated Fee Collection*, *Teacher AI V2*, *Donation & Waqf Tracking*).

2. **2D Animated Story: *"A Tale of Two Campuses"***:
   - Real problem-to-success narrative showing the daily struggle vs cloud transformation.
   - **Madrasa Scenario vs School Scenario** toggle.
   - 4 Time Stations: `08:30 AM (Gate & Attendance)`, `11:30 AM (Teachers & AI)`, `02:00 PM (Accounts & Waqf)`, `05:00 PM (Committee & BI)`.
   - Interactive Before/After drag slider comparing the manual paper era to the automated cloud era.

3. **Video Showcase Theatre**:
   - Glassmorphic cinema screen with interactive chapters:
     1. Biometric Gateway & Instant Parent SMS
     2. Automated Tuition Collection via bKash & Double-Entry Ledger
     3. Teacher Assistant AI V2: NCTB Syllabus Question Paper Maker
     4. Madrasa Waqf Fund & Residential Dormitory Bed Allocator
   - Full-screen modal player for presenting client promotional videos.

4. **All 9 Institutional Modules (from Official Proposal)**:
   - 3D perspective tilt cards covering:
     1. Website & Dynamic Frontend CMS
     2. Student & Parent Lifecycle Management
     3. Biometric Attendance Sync (ZKTeco API)
     4. Double-Entry Financial Accounting
     5. Donation & Waqf Fund Tracking (Specialized for Madrasas)
     6. AI Teacher Assistant Ecosystem (V1 & V2)
     7. Dormitory / Hostel Bed & Fleet Transport
     8. Library Barcode & Asset Inventory
     9. ID Cards, Certificates & Executive BI Analytics

5. **Interactive Pricing & ROI Calculator**:
   - Real-time student count slider (100 to 3,000+ students).
   - Instant calculation for **Starter (৳5)**, **Professional (৳8)**, and **Enterprise (৳12)** per student per month.
   - ROI Value metrics: estimated paper saved (৳), recovered unpaid dues (৳), and staff overtime hours saved.

6. **Full Module & Feature Comparison Matrix**:
   - Line-by-line comparison table directly reflecting Page 2 of the official proposal document.

7. **4-Stage Onboarding Roadmap**:
   - Stage 01: Cloud Deployment ➔ Stage 02: Data Migration ➔ Stage 03: Staff Training ➔ Stage 04: Official Go-Live.

8. **Localization & Conversion Hooks**:
   - Dual-language toggle: English & বাংলা.

## 🚀 How to Run Locally

You can serve the project using Python's built-in HTTP server:

```bash
# In the project directory:
python3 -m http.server 8000
```

Then open your browser and navigate to:
```
http://localhost:8000
```

## 🌐 How to Deploy to Vercel (Like yes-sme.vercel.app)

Since this project is pure HTML, CSS, and JavaScript with zero build steps, you can deploy it to Vercel in 1 click:

1. Push this folder to a GitHub repository.
2. In [Vercel Dashboard](https://vercel.com), click **Add New Project** and select your repository.
3. Keep default settings (Static site) and click **Deploy**.
4. Your site will be live instantly on `https://yes-edu.vercel.app`!
